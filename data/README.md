# Dataset Directory

Place the Kaggle Fake and Real News dataset CSV files here:

- `Fake.csv`
- `True.csv`

Dataset Source:
https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

Expected Columns:
- `title`
- `text`
- `subject`
- `date`

Once the CSV files are placed in this folder, run:
```bash
python train.py
```
